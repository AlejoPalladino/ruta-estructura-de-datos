Fibonacci: llamadas y retornos
F(0)=0, F(1)=1. Para n≥2, F(n)=F(n−1)+F(n−2).
Una llamada espera a sus hijos antes de retornar. La versión ingenua repite subproblemas: tiempo exponencial y profundidad O(n). Los acumuladores reducen el trabajo a O(n); Python conserva las llamadas en la pila.
Recursividad: bajar y volver
Una llamada devuelve un resultado, no solo ejecuta la siguiente. Seguí la suma de [2, 3, 4].
def suma_recursiva(v):
    if len(v) == 0:
        return 0
    return v[0] + suma_recursiva(v[1:])
